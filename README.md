Программный комплекс для численного решения одномерных краевых задач для обыкновенных дифференциальных уравнений (ОДУ) второго порядка. 
Проект состоит из высокопроизводительного математического ядра на **C++** и современного интерактивного графического интерфейса на **Python (PySide6 / QML)** с использованием Material Design.

Вариант задания: **2 (и 2в для смешанной задачи)**.

## Основные возможности
* **Разделение логики:** Вычислительно сложные матричные операции (метод прогонки) реализованы на C++ в виде разделяемой библиотеки (`.dll` / `.so`).
* **Анализ точности:** Для тестовых задач вычисляется точное аналитическое решение и находится погрешность $\epsilon_1$.
  * Для основных задач применяется оценка точности по правилу Рунге (сравнение решений на сетках $n$ и $2n$) для поиска $\epsilon_2$.
* **Интерактивные графики:** Полноценный вьювер (QtCharts) с возможностью перемещения (Drag & Pan) и масштабирования (Zoom) с помощью колесика мыши.
* **Высокоскоростные таблицы:** Отрисовка сырых данных без зависаний благодаря кастомной модели `QAbstractTableModel`, работающей напрямую с массивами `numpy`.

## Инструкция по запуску

Для работы программы необходимо собрать математическое ядро (C++) и установить зависимости интерфейса (Python).

### Системные требования

* **C++:** Компилятор с поддержкой C++17 (MSVC, GCC, Clang) и CMake (>= 3.10)
* **Python:** Версия 3.8 или выше

---

### Шаг 1: Сборка C++ ядра

Откройте терминал в корневой папке проекта.

**Для Windows (PowerShell):**

```powershell
mkdir build
cd build
cmake ..
cmake --build . --config Release
cd ..

```

**Для Linux (Bash):**

```bash
mkdir -p build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
make
cd ..

```

*После сборки в папке `build` появится файл `solver.dll` (Windows) или `libsolver.so` (Linux).*

---

### Шаг 2: Настройка Python-окружения

Рекомендуется использовать виртуальное окружение, чтобы не засорять систему. В терминале в корне проекта выполните:

1. Создание виртуального окружения:
```bash
python -m venv venv
```


2. Активация окружения:
* **Windows:** `.\venv\Scripts\activate`
* **Linux/macOS:** `source venv/bin/activate`

3. Установка библиотек (PySide6, numpy):
```bash
pip install -r requirements.txt
```

---

### Шаг 3: Запуск приложения

Убедитесь, что виртуальное окружение активировано (в терминале горит префикс `(venv)`), и запустите главный файл:

```bash
python main.py
```
